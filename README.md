# 💰 SmartSpend AI

SmartSpend AI is a full-stack personal finance management application built with Flutter and Node.js.

It helps users manage their expenses, income, budgets, analytics, and financial insights from a single application.

---

## 🚀 Features

### 🔐 Authentication
- User Registration
- User Login
- JWT Authentication
- Secure JWT Token Storage
- Logout
- Protected APIs

### 💸 Expense Management
- Add Expense
- View Expenses
- View Single Expense
- Update Expense
- Delete Expense
- Expense Categories
- Search Expenses
- Sort Expenses
- Date Filtering

### 💵 Income Management
- Add Income
- View Income
- Income History
- Income Tracking

### 📊 Analytics
- Expense Analytics
- Category-wise Spending
- Monthly Spending
- Weekly Spending
- Spending Trends
- Financial Health
- Spending Score
- Highest Spending Day
- AI-based Insights

### 💰 Budget Management
- Set Budget
- Track Budget
- Budget Progress
- Budget Alerts

### 📄 Reports
- Generate PDF Reports
- Export Financial Data
- Share Reports

### 🤖 AI Features
- Spending Analysis
- Financial Insights
- Savings Suggestions
- Monthly Predictions
